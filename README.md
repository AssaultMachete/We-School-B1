# We-School-B1

This repository contains practical web-development materials for the B1 class, organized into Unit 9 and Unit 10.

## Unit 9 — Practical Activities

The `Codes/Practical` folder contains HTML exercises and, where applicable, CSS stylesheets and supporting assets:

- Activity 1: A WE School page with program and contact sections.
- Activities 2 and 3: Login and registration pages.
- Activity 4: A booking form.
- Activities 5 and 6: WE School page exercises.
- Activity 6 (Card): A simple card layout.
- Activity 7: Button examples.
- Activity 8: A navigation bar.
- Activity 9: A page header.

Some activities include ZIP files or image assets alongside the source files.

## Unit 10 — Field Training

`Field Training/Session 1` contains a school website project, including HTML, CSS, and image assets. The page introduces the school and presents its programs, teachers, and community.

## Getting Started

Open an activity's HTML file in a web browser to view it. For activities that include a stylesheet or image assets, keep those files in their existing folders so the page can load them correctly.
